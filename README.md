# 🏆 achievement-hunt

A self-contained playground that unlocks earnable GitHub achievements
via a single, re-runnable GitHub Actions workflow.

Targets:
- 🎯 **Quickdraw** — open + close an issue within 5 minutes
- 🤠 **YOLO** — merge a pull request with no review
- 👯 **Pair Extraordinaire** — merge a co-authored pull request

Trigger from the **Actions** tab → *Achievement Hunt* → *Run workflow*.
